## Keystone Type Assignments

Based on the PDF research:

### Lepidoptera Host Plants
- **Keystone Type**: `host_plant_lepidoptera`
- **Keystone Description**: "Serves as host plant for butterfly and moth caterpillars. Native species critical for Lepidoptera reproduction."
- **Examples**: All trees (Quercus, Prunus, Betula, Populus, etc.)

### Specialist Bee Plants
- **Keystone Type**: `specialist_bee_forage`
- **Keystone Description**: "Primary pollen source for specialist native bees; only these plants provide necessary nutrition for certain bee species."
- **Examples**: Goldenrod, Sunflower, Aster, etc.

### Dual Keystone (Both)
- **Keystone Type**: `dual_keystone`
- **Keystone Description**: "Critical host plant for Lepidoptera AND primary pollen source for specialist bees."
- **Examples**: Solidago, Helianthus, Rudbeckia, Salix, Vaccinium

## Notes for Implementation

1. **Region**: All plants should use `"region": "northeast_pa"` (applies to Northern Forests ecoregion)
2. **Is Keystone**: `true` for ALL species on this list (by definition from PDF)
3. **Symbiosis**: Many existing species already have relationships (e.g., Monarchs ↔ Milkweed) - these new plants will expand that network
4. **Images**: Use high-quality Wikimedia Commons photos with author attribution where available
5. **Form Field**: Specify `tree`, `shrub`, or `wildflower` for clearer categorization
6. **Behavior**: Trees should include `host_plant` behavior; wildflowers should include `nectar_source` and `pollen_source`
